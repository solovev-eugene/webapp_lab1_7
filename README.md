# Веб-приложение на Flask (Лабораторная работа №1.7)

## Описание

Это веб-приложение, разработанное на Python с использованием микрофреймворка Flask. Проект создан в рамках выполнения лабораторной работы и демонстрирует базовую структуру веб-приложения с маршрутами, работой с формами, статическими файлами и шаблонами.

Приложение служит основой для дальнейшего развития и изучения возможностей Flask, включая обработку пользовательского ввода, валидацию данных и взаимодействие с окружением.

## Установка

## СПОСОБ 1

Для запуска проекта на вашем локальном компьютере выполните следующие шаги:

1.  **Клонируйте репозиторий:**

```bash
git clone https://github.com/solovev-eugene/webapp_lab1_7.git
cd webapp_lab1_7
```

2. Создайте и активируйте виртуальное окружение (рекомендуется):
  
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
venv\Scripts\activate  # Для Windows
```

3. Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

4. Настройте переменные окружения: cкопируйте файл .env.example в .env и заполните его своими данными (например, секретные ключи или настройки сервера).
	
```bash
cp .env.example .env
```

## CПОСОБ 2

Запустите скрипт 
```bash
source quick_install.sh
```
## Использование

После выполнения всех шагов по установке, запустите приложение:

```python
python app.py
```

Откройте ваш веб-браузер и перейдите по адресу http://127.0.0.1:5000. Вы увидите главную страницу приложения. Далее вы можете взаимодействовать с ним через интерфейс, переходя по доступным ссылкам и заполняя формы.
Структура проекта

Проект имеет следующую стандартную структуру:

webapp_lab1_7/
├── app.py              # Главный файл приложения, где создается экземпляр Flask
├── config.py           # Файл конфигурации приложения
├── forms.py            # Определение форм
├── utils.py            # Вспомогательные функции и утилиты
├── requirements.txt    # Список зависимостей Python
├── .env.example        # Пример файла с переменными окружения
├── .gitignore          # Список файлов и папок, игнорируемых Git
├── static/             # Папка для статических файлов (CSS, JavaScript, изображения)
│   └── (ваши файлы)
└── templates/          # Папка с HTML-шаблонами (используется Jinja2)
    └── (ваши шаблоны)
